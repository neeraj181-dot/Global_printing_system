## What's New?

### 1. 💬 Simple Chatbot
- Floating chat button in bottom-right corner
- Instant answers to common questions

- Available on Dashboard and Orders pages

**Try it:** Click the 💬 button!

- Upload multiple files at once

- One-click login with Google
- No password needed

**Try it:** Click "Continue with Google" on login page!

---

## Quick Start

### Using Multiple Upload:
1. Go to Dashboard
2. Click upload area
3. Select multiple files (Ctrl+Click)
4. Configure print options
5. Submit order

### Using Chatbot:
1. Click 💬 button (bottom-right)
2. Ask a question or use quick replies
3. Get instant answers
4. Close when done

### Using Google Login:
1. Go to Login page
2. Click "Continue with Google"
3. Select your Google account
4. Done! You're logged in
